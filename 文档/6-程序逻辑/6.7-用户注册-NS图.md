# 6.7 用户注册算法 — N-S图

```
┌─────────────────────────────────────────────────────────────┐
│  输入: username, password, confirmPassword                   │
├─────────────────────────────────────────────────────────────┤
│  前端校验:                                                   │
│  ┌─────────────────────────────────────────────────────────┐ │
│  │ username 非空?                                           │ │
│  │  ┌──────┬─────────────────────────────────────────────┐ │ │
│  │  │ 否   │ 显示错误: 用户名不能为空                     │ │ │
│  │  └──────┴─────────────────────────────────────────────┘ │ │
│  │ password 长度 >= 6?                                      │ │
│  │  ┌──────┬─────────────────────────────────────────────┐ │ │
│  │  │ 否   │ 显示错误: 密码长度不能少于6位                │ │ │
│  │  └──────┴─────────────────────────────────────────────┘ │ │
│  │ password = confirmPassword?                              │ │
│  │  ┌──────┬─────────────────────────────────────────────┐ │ │
│  │  │ 否   │ 显示错误: 两次密码不一致                     │ │ │
│  │  └──────┴─────────────────────────────────────────────┘ │ │
│  └─────────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│  发送 POST /auth/register 请求                               │
├─────────────────────────────────────────────────────────────┤
│  后端处理:                                                   │
│  ┌─────────────────────────────────────────────────────────┐ │
│  │ 查询用户名是否已存在                                     │ │
│  │  ┌──────────────┬──────────────────────────────────────┐ │ │
│  │  │ 已存在       │ 不存在                                │ │ │
│  │  ├──────────────┤                                      │ │ │
│  │  │ 返回错误     │ BCrypt加密密码                        │ │ │
│  │  │              │ 创建User记录                          │ │ │
│  │  │              │ 插入数据库                            │ │ │
│  │  └──────────────┴──────────────────────────────────────┘ │ │
│  └─────────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│  返回注册成功 → 跳转登录页                                   │
└─────────────────────────────────────────────────────────────┘
```
