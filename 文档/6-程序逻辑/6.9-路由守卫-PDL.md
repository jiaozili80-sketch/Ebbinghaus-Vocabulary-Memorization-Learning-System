# 6.9 前端路由守卫算法 — PDL语言

```pdl
PROCEDURE router.beforeEach(to, from, next)
    // 获取存储的Token
    token ← localStorage.getItem("token")

    // 定义不需要认证的白名单路由
    whitelist ← ["/login", "/register"]

    IF token EXISTS THEN
        // 已登录状态
        IF to.path = "/login" OR to.path = "/register" THEN
            // 已登录访问登录页，重定向到首页
            next("/dashboard")
        ELSE
            // 检查是否需要管理员权限
            IF to.meta.requiresAdmin THEN
                userInfo ← JSON.parse(localStorage.getItem("userInfo"))
                IF userInfo.role = "ADMIN" THEN
                    next()
                ELSE
                    next("/dashboard")  // 无权限，重定向
                    SHOW message("无访问权限")
                END IF
            ELSE
                next()  // 正常放行
            END IF
        END IF
    ELSE
        // 未登录状态
        IF whitelist CONTAINS to.path THEN
            next()  // 白名单路由放行
        ELSE
            next("/login")  // 重定向到登录页
        END IF
    END IF
END PROCEDURE
```
