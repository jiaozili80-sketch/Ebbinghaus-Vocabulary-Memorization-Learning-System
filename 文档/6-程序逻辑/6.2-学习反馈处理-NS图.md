# 6.2 学习反馈处理算法 — N-S图（盒图）

```
┌─────────────────────────────────────────────────────────────────┐
│  输入: wordId, familiarity(1/2/3), duration                      │
│  从 LoginUserContext 获取 userId                                  │
├─────────────────────────────────────────────────────────────────┤
│  查询 ReviewPlan (userId, wordId)                                │
├──────────────┬──────────────────────────────────────────────────┤
│ ReviewPlan   │                                                  │
│ 不存在?      │  存在                                             │
├──────────────┤                                                  │
│ 返回错误     │                                                  │
│ 结束         │                                                  │
├──────────────┴──────────────────────────────────────────────────┤
│  获取当前 stage                                                  │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────────┬────────────────┬─────────────────────────┐ │
│  │ familiarity<=1  │ familiarity==2 │ familiarity>=3          │ │
│  ├─────────────────┼────────────────┼─────────────────────────┤ │
│  │ newStage = 0    │ newStage =     │ newStage =              │ │
│  │                 │ max(0,stage-1) │ min(7, stage+1)         │ │
│  └─────────────────┴────────────────┴─────────────────────────┘ │
├─────────────────────────────────────────────────────────────────┤
│  nextReviewTime = now + intervals[newStage]                      │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────┬──────────────────────────────┐ │
│  │ familiarity>=3 AND          │ 否                           │ │
│  │ newStage==7?                │                              │ │
│  ├─────────────────────────────┼──────────────────────────────┤ │
│  │ status = 1 (已掌握)         │ status = 0 (继续复习)        │ │
│  └─────────────────────────────┴──────────────────────────────┘ │
├─────────────────────────────────────────────────────────────────┤
│  更新 ReviewPlan: stage, nextReviewTime, status, familiarity     │
├─────────────────────────────────────────────────────────────────┤
│  ┌─────────────────────────────────────────────────────────────┐ │
│  │ familiarity <= 2 ?                                          │ │
│  │  ┌──────────┬──────────────────────────────────────────┐   │ │
│  │  │ 是       │                                          │   │ │
│  │  │          │ WrongWord存在?                           │   │ │
│  │  │          │  ┌──────┬──────────────────────────────┐ │   │ │
│  │  │          │  │ 是   │ 否                           │ │   │ │
│  │  │          │  │      │                              │ │   │ │
│  │  │          │  │count+1│ 创建新WrongWord             │ │   │ │
│  │  │          │  └──────┴──────────────────────────────┘ │   │ │
│  │  └──────────┴──────────────────────────────────────────┘   │ │
│  └─────────────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────────┤
│  更新 StudyRecord (new_word_count 或 review_word_count + 1)      │
├─────────────────────────────────────────────────────────────────┤
│  更新 User 统计 (total_words, mastered_words)                    │
├─────────────────────────────────────────────────────────────────┤
│  输出: newStage, nextReviewTime, isMastered                      │
└─────────────────────────────────────────────────────────────────┘
```
