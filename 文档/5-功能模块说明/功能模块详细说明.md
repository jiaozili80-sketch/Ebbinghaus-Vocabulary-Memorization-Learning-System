# 功能模块详细说明

---

## 1. 用户管理模块

**功能概述：** 负责用户的注册、登录、身份认证和权限管理。

| 子功能 | 描述 | API端点 | 请求方式 |
|--------|------|---------|----------|
| 用户注册 | 新用户填写用户名、密码进行注册 | `/auth/register` | POST |
| 用户登录 | 已注册用户登录获取JWT Token | `/auth/login` | POST |
| 获取用户信息 | 根据Token获取当前用户详情 | `/auth/me` | GET |
| JWT认证拦截 | 拦截`/api/**`请求验证Token | - | - |

**关键类：**
- `AuthController` — 处理认证相关HTTP请求
- `AuthService` — 注册、登录业务逻辑
- `JwtUtil` — JWT生成与解析
- `JwtAuthInterceptor` — 请求拦截与Token验证
- `LoginUserContext` — ThreadLocal存储当前用户ID

**数据流向：**
```
用户 → AuthController → AuthService → UserMapper → MySQL
                  ↓
            JwtUtil(生成Token) → 返回LoginVO → 前端localStorage
```

## 2. 词汇管理模块

**功能概述：** 管理词书和词汇数据，支持用户浏览、选择词书。

| 子功能 | 描述 | API端点 | 请求方式 |
|--------|------|---------|----------|
| 词书列表 | 获取所有可用词书 | `/wordbook/list` | GET |
| 词书详情 | 获取词书包含的词汇数量等信息 | `/wordbook/{id}` | GET |
| 词汇查询 | 根据词书ID查询词汇列表 | `/word/book/{bookId}` | GET |
| 错词本 | 获取用户错词列表 | `/wrong-word/list` | GET |

**数据模型：**
```
word_book: id, name, category, type(1公共/2私有), word_count
word: id, book_id, spelling, phonetic, meaning, example_sentence, difficulty
wrong_word: id, user_id, word_id, wrong_count, created_at
```

## 3. 学习引擎模块（核心）

**功能概述：** 系统核心模块，实现基于艾宾浩斯遗忘曲线的间隔重复学习。

| 子功能 | 描述 | API端点 | 请求方式 |
|--------|------|---------|----------|
| 学习概览 | 获取新词/复习/已掌握/错词数量 | `/study/overview` | GET |
| 今日任务 | 获取今日到期的复习任务 | `/study/today` | GET |
| 开始新词 | 获取未学习单词并创建初始计划 | `/study/new` | POST |
| 提交反馈 | 提交熟悉度评价，更新复习计划 | `/study/submit` | POST |

**核心算法 — 艾宾浩斯间隔重复：**

```
间隔时间表（分钟）: [5, 30, 720, 1440, 2880, 5760, 10080, 21600]
对应实际时间:        5分 30分 12时 24时 2天  4天  7天   15天

输入: familiarity (1=不认识, 2=模糊, 3=认识), currentStage (0-7)
输出: newStage, nextReviewTime

算法:
  IF familiarity <= 1 THEN
      newStage = 0  (重置)
  ELSE IF familiarity == 2 THEN
      newStage = max(0, currentStage - 1)  (降一级)
  ELSE IF familiarity >= 3 THEN
      newStage = min(7, currentStage + 1)  (升一级)

  nextReviewTime = now + intervals[newStage]

  IF familiarity >= 3 AND newStage == 7 THEN
      status = 1  (已掌握)
```

## 4. 统计分析模块

**功能概述：** 提供学习数据的可视化展示，帮助用户了解学习进度。

| 子功能 | 描述 | API端点 | 请求方式 |
|--------|------|---------|----------|
| 学习进度 | 总词数、已掌握、学习中、错词数 | `/statistics/progress` | GET |
| 学习曲线 | 每日学习数量趋势图 | `/statistics/trend` | GET |
| 打卡记录 | 连续打卡天数和历史记录 | `/statistics/checkin` | GET |
| 每日目标 | 设置和完成每日学习目标 | `/daily-goal` | GET/POST |

**数据模型：**
```
study_record: id, user_id, study_date, new_word_count, review_word_count, study_duration
checkin_record: id, user_id, checkin_date, is_checked
daily_goal: id, user_id, new_word_target, review_word_target
```
